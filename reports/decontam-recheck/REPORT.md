# KodCode 与 HumanEval+/MBPP+ 更严格去污染复查（2026-10-02，协议 v4 补充 4 第 3 条）

只比较题面文本，不读取任何模型输出；最终评测从未运行。

## 做法

1. **预先声明的一轮**（`scripts/decontam_recheck_kodcode.py`，标准在运行前写入脚本）：KodCode 全部 3745 题（第一阶段筛选池 1165〔含已训练 248 + 延长 138〕、开发集 350、测试集 295、第二阶段 shard2 池 1935）对 HumanEval+ 164 / MBPP+ 378 全部任务；标记条件 A 非模板词 8-gram 共享、B TF-IDF 余弦 ≥ 0.45、C 同名函数且余弦 ≥ 0.20。
   - 结果：B 无命中（全体最高余弦仅 0.31）；A 的 208 对几乎全是常见措辞（"takes a list of integers as an input"等）；C 4 对。
   - **结论：0.45 的余弦阈值不适用**——KodCode 的 Evol 题面很长，把相似度稀释了，真正的同题（如 HumanEval/157 判断直角三角形 ≈ Evol_3003，余弦 0.31）也达不到。
2. **补充筛查（看过第 1 轮结果后加的，只会多查不会少查）**（`scripts/decontam_review_candidates.py`）：只看**已训练题**和 **shard2 池**，列出余弦 ≥ 0.12 或函数名词元 Jaccard ≥ 0.5 的配对，逐对人工复核。"同一任务"= 要求的函数行为相同（同类输入、同样输出），不是同一话题。
